نظام إدارة المطاعم والكافيهات — مشروع كامل قابل للنشر على Cloudflare Workers + D1

المزايا المضمنة:
- إنشاء حساب وتسجيل دخول، جلسات آمنة بكوكي HttpOnly، وتخزين بيانات على D1.
- إعداد اسم المطعم/الكافيه والعنوان والهاتف والرقم الضريبي ورابط الشعار.
- إدارة أصناف وأسعار.
- فواتير تحتوي الأصناف والكميات والخصم والضريبة والخدمة وطريقة الدفع والطاولة والكاشير ونوع الطلب.
- رقم فاتورة متسلسل لكل مطعم، وحفظ تفاصيل الفاتورة وصورة بيانات المطعم وقت إصدارها.
- معاينة الفاتورة وطباعتها أو حفظها PDF من المتصفح، مع QR.
- المبيعات حسب الفترة، تصدير CSV.
- تسجيل المصروفات.
- إغلاق اليوم مرة واحدة، وحساب النقدية المتوقعة والفرق مع النقدية الفعلية، وحفظ تقرير الإغلاق.
- سجل عمليات تدقيق أساسي.
- قاعدة بيانات SQL وفهارس.

طريقة الإعداد:
1) أنشئ قاعدة Cloudflare D1 جديدة باسم restaurant-cafe-pos-db؛ لا تستخدم قاعدة eldab3awy-db القديمة.
2) استبدل REPLACE_WITH_YOUR_NEW_D1_DATABASE_ID في wrangler.jsonc بمعرّف قاعدة المطاعم الجديدة.
3) اربط قاعدة المطاعم الجديدة بالإعدادات، ثم نفّذ من مجلد المشروع:
   npx wrangler d1 execute restaurant-cafe-pos-db --remote --file=./schema.sql
4) ثبّت Wrangler إذا لزم:
   npm install -D wrangler
5) انشر:
   npx wrangler deploy
6) افتح رابط Worker، أنشئ حساب المسؤول الأول، ثم املأ إعدادات المطعم.
7) احتفظ بنسخة احتياطية دورية من D1، واختبر الطباعة على الطابعة الفعلية قبل الاستخدام اليومي.

ملاحظات مهمة:
- يجب تشغيله على HTTPS (رابط Cloudflare Worker مناسب) لأن كوكي الجلسة Secure.
- إعدادات الضريبة والخدمة افتراضية قابلة للتعديل. تأكد من مطابقتها للمعاملة والقواعد الضريبية المصرية قبل اعتماد النظام ماليًا.
- QR يستخدم خدمة توليد صور QR خارجية عند العرض، لذلك يتطلب إنترنت. عند إدخال رابط منيو/موقع، يوجّه QR إليه؛ وإلا يحتوي بيانات تعريف الفاتورة.
- طباعة PDF تتم عبر مربع الطباعة في المتصفح، ولا يوجد اعتماد على خدمة PDF مدفوعة.
- هذه حزمة مشروع قابلة للنشر وليست شهادة امتثال ضريبي أو نظامًا معتمدًا للفوترة الإلكترونية. لا تطبع رمزًا ضريبيًا رسميًا غير صادر من الجهة المختصة.
- حماية النظام وعمليات الدفع تحتاج اختبارًا أمنيًا وتشغيليًا قبل التعامل مع أموال حقيقية. النسخة الحالية لا تدعم تعدد الفروع/المستخدمين بصلاحيات تفصيلية أو تعديل/إلغاء الفواتير النهائية؛ لا تحذف السجلات المالية.
